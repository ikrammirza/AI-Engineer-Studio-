# AI Engineer Studio

A local-first LLMOps and AI Agent platform for building, evaluating,
debugging, and observing LLM applications.

## Goals

- Local LLM inference
- Prompt versioning
- RAG pipelines
- AI agents
- Multi-agent workflows
- LLM evaluation
- AI observability
- Model experimentation
- RAG debugging
- Background processing
- Production deployment

## Initial Stack

### Frontend
- Next.js
- TypeScript

### Backend
- Python
- FastAPI

### AI
- Ollama
- Qwen 2.5 Coder 7B

### Database
- PostgreSQL
- pgvector

### Infrastructure
- Redis
- Docker
